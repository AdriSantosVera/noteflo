# Hooks

Esta carpeta está reservada para hooks reutilizables del frontend Expo.

Aquí deben vivir hooks agnósticos de pantalla, por ejemplo:

- sincronización de estado derivado
- utilidades de formulario
- lógica compartida entre pestañas

Si un hook pertenece a una funcionalidad concreta, debe vivir junto a esa funcionalidad y no aquí.
